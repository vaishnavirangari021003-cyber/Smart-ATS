# HireFlow — Smart Recruitment & Applicant Tracking System (ATS)

This folder contains the complete multi-page frontend implementation of **HireFlow**, an enterprise-grade Smart Applicant Tracking System built with vanilla HTML5, CSS3, and ES modules.

### Quick Start
Open `hireflow/index.html` in your browser or launch a static server (e.g. VS Code Live Server or `python -m http.server 8000`).

For the complete technical documentation, architecture, API mapping, permission matrix, and testing guide, see **[hireflow/README.md](hireflow/README.md)**.
